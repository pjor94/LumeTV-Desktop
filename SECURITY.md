# Segnalazioni di sicurezza

Lume TV Desktop è in fase sperimentale; non esiste ancora una serie di release
stabili con un periodo di supporto dichiarato. Le correzioni riguardano il codice
corrente. L’app non dispone ancora di aggiornamenti automatici.

Per una vulnerabilità usa la segnalazione privata nella scheda **Security** del
repository, se abilitata. Se il canale non è disponibile, apri una richiesta
pubblica di contatto privato senza includere dettagli di sfruttamento o dati
sensibili.

Indica commit, piattaforma, architettura, componente interessato, impatto e i
passaggi minimi per riprodurre il problema con dati sintetici. Non inviare il tuo profilo
browser, cookie, credenziali, URL firmati o messaggi DRM.

Le API dell’app sono locali e richiedono un token di sessione. I provider e il
CDM vengono contattati dal dispositivo dell’utente. Per il comportamento atteso
del relay e delle prove consulta [il protocollo](docs/VALIDATION.md).
